# Portfolio Lissette Ivonne | Actriz & Profesora de Danza

Site portfolio interactif et responsive pour Lissette Ivonne, construit avec HTML5, Tailwind CSS (CDN), et JavaScript natif.

## 🚀 Lancement en local

Pour tester et prévisualiser le site sur votre machine sans problème de chargement des ressources médias (images / vidéos), vous pouvez utiliser un serveur local léger.

### Option 1 : Avec Node.js (`npx`) — *Recommandé*
Ouvrez votre terminal dans le dossier du projet et exécutez :

```bash
npx serve .
```
> Le site sera accessible à l'adresse `http://localhost:3000`.

### Option 2 : Avec Python 3
Si vous avez Python installé sur votre système :

```bash
python -m http.server 8000
```
> Le site sera accessible à l'adresse `http://localhost:8000`.

### Option 3 : Visual Studio Code (Extension)
1. Installez l'extension **Live Server** dans VS Code.
2. Ouvrez le fichier `index.html`.
3. Cliquez sur **« Go Live »** en bas à droite de la fenêtre.
